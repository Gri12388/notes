### Структура проекта

В папке /99_diploma находится финальный проект. Он состоит из двух частей: серверной и клиентской, - которые расположены в папках /server и /client соответственно.

### Запуск проекта

Для запуска приложения необходимо

1. перейти в папку /99_diploma/server
2. установив все зависимости командой

`npm i`

3. создать в папке /99_diploma/server конфигурационный файл .env, заполнив его содержанием файла .env.sample
4. выполнить команду

`npm run start`

В случае необходимости инициализации базы данных Postgresql нужно выполнить скрипт миграции, указав команду

`npm run migrate`

### Разработка проекта

Для запуска программы в режиме разработки необходимо выполнить команду

`npm run dev`

Для выполнения сборки сервера используется команда

`npm run build`

Для выполнения сборки клиента необходимио перейти в папку /99_diploma/server и выполнить команду

`npm run build`
